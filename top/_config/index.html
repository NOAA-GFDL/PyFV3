    AcousticDynamicsConfig dataclass

    breed_vortex_inline instance-attribute

    setting for nudging where we can insert tropical cyclone tracks and add fake tropical cyclones at a certain point in the code not used so much right now because we can run at high enough resolution to directly nudge to tropical cyclone data

    use_old_omega instance-attribute

    mainly for backwards compatibility, not really used anymore

    DynamicalCoreConfig dataclass

    cld_min = 0.05 class-attribute instance-attribute

    !< minimum cloud fraction

    do_skeb = False class-attribute instance-attribute

    save dissipation estimate

    dw_land = 0.15 class-attribute instance-attribute

    base value for subgrid deviation / variability over land

    dw_ocean = 0.1 class-attribute instance-attribute

    base value for ocean

    qi0_max = 0.0001 class-attribute instance-attribute

    max cloud ice value (by other sources)

    qi_gen = 1.82e-06 class-attribute instance-attribute

    max cloud ice generation during remapping step

    qi_lim = 1.0 class-attribute instance-attribute

    cloud ice limiter to prevent large ice build up

    ql0_max = 0.002 class-attribute instance-attribute

    max cloud water value (auto converted to rain)

    ql_mlt = 0.002 class-attribute instance-attribute

    max value of cloud water allowed from melted cloud ice

    qs_mlt = 1e-06 class-attribute instance-attribute

    max cloud water due to snow melt

    rad_graupel = True class-attribute instance-attribute

    consider graupel in cloud fraction calculation

    rad_rain = True class-attribute instance-attribute

    consider rain in cloud fraction calculation

    rad_snow = True class-attribute instance-attribute

    consider snow in cloud fraction calculation

    sat_adj0 = 0.9 class-attribute instance-attribute

    adjustment factor (0: no 1: full) during fast_sat_adj

    sw_dynamics = False class-attribute instance-attribute

    shallow water conditions

    t_sub = 184.0 class-attribute instance-attribute

    min temp for sublimation of cloud ice

    tau_g2r = 600.0 class-attribute instance-attribute

    graupel melting to rain

    tau_g2v = 1200.0 class-attribute instance-attribute

    graupel sublimation

    tau_i2s = 1000.0 class-attribute instance-attribute

    cloud ice to snow auto - conversion

    tau_imlt = 600.0 class-attribute instance-attribute

    cloud ice melting

    tau_l2r = 900.0 class-attribute instance-attribute

    cloud water to rain auto - conversion

    tau_l2v = 300.0 class-attribute instance-attribute

    cloud water to water vapor (evaporation)

    tau_r2g = 900.0 class-attribute instance-attribute

    rain freezing during fast_sat

    tau_smlt = 900.0 class-attribute instance-attribute

    snow melting

    tau_v2g = 21600.0 class-attribute instance-attribute

    graupel deposition -- make it a slow process

    tau_v2l = 90.0 class-attribute instance-attribute

    water vapor to cloud water (condensation)

    tintqs = False class-attribute instance-attribute

    use temperature in the saturation mixing in PDF

    u_max = 350.0 class-attribute instance-attribute

    max windspeed for dp config
