    a2b_ord4

    AGrid2BGridFourthOrder

    Fortran name is a2b_ord4, test module is A2B_Ord4

    __call__(qin, qout)

    Converts qin from A-grid to B-grid in qout.

    If initialized with replace=True, qin is also updated to the B grid.
